
# Robot_Arm

## 项目简介
本项目为一个多自由度的机械臂系统，包含机械结构设计、固件开发（基于Arduino）、OpenMV视觉识别、以及多种应用示例（如物块抓取、垃圾分类、三子棋等）。适用于机器人学习、人工智能实验、机械臂控制等场景。

## Project Description
This project is a multi-degree-of-freedom desktop robotic arm system, including mechanical design, firmware development (Arduino-based), OpenMV vision recognition, and various application examples (such as object grasping, garbage classification, tic-tac-toe, etc.). It is suitable for robotics learning, AI experiments, and robotic arm control scenarios.
